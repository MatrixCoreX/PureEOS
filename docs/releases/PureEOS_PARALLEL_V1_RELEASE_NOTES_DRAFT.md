# PureEOS 并行首版发布说明草稿

2026-10-25。尚未正式发布。本文件用于最终验收和发布准备；正式 tag、下载地址及完整通过报告待核验后填写。AIC CDT 的独立产品版本为 1.0.0。

本版面向新创世链。不同交易可在私有状态中并行执行，正式状态仍按区块交易顺序提交。提交前核对读取依赖，冲突、能力不支持或预算耗尽时采用受控重试或串行路径。同一笔交易内部的 action、inline 和同步调用保留执行顺序及整体回滚语义。

首版配置支持至多 16 个 worker、每批至多 64 笔交易。合约须按实际 WASM 摘要显式允许并行；升级后重新核验。worker 数量不代表处理能力提升倍数。生产与验证使用匹配的 eos-vm-jit，不并发写正式 Chainbase。

配套新链规则包括：按票数确定候选名次，初始候选上限 210、按四年翻倍的斜率线性扩容；最多 21 人在岗，按队列顺序每次更换一人；从单节点原生 Savanna 创世逐步接入新节点。满 21 人时，连续三个完整本人窗口零产出会使该账号永久禁止再次轮岗；不足 21 人不拉黑。不冻结资产、不没收已有出块收益。

节点收益只按实际出块分配，取消备用节点与投票奖励。去除原 15% 投票激活门槛；取消原储备部分增发，节点初始年增发约 1%，奖励率每四年减半。直接质押与 REX 租赁合计约 10% 的资源空间，其余由 PowerUp 提供。保留资源租赁；投票采用最小单位整数、一票一投，取消代理投票，买入 REX 要求有效投票。

系统升级由指定开发者账号发起，固定公示 14 天，按合约记录的合法候选快照统计反对票，达到规定三分之二反对门槛时阻止升级。普通矿工不通过 eosio.msig 管理系统升级；账号管理、开发者升级与出块/最终确认签名密钥分别配置。

本轮恢复修复保留活动 durable recovery journal、原区块日志备份和独立 finalizer 安全信息。恢复历史 header 不再立即耗尽实时缺票观察窗口；原缺少真实投票的超时保护仍保留。真实双 VM 停启后已验证实际 journal 恢复、新的出块及最终确认；具体摘要和原始失败见验收清单。

源码构建适配 Ubuntu 26.04 / 26.10 x86_64 用户空间。当前运行包实际构建、运行于 Ubuntu 26.10 用户空间，不宣称适用于所有 Linux、ARM 或 Windows。AIC CDT 1.0.0 包含重编的五个前端、搬迁后的 CMake/项目生成修复与完整依赖许可声明；其 LLVM 后端保持固定上游基线，不宣称升级了 LLVM 主版本。

首次发布以后，使用同一发布程序在单台节点对比串行与 4/8/12/16 worker 的 TPS。独立转账、简单合约、复杂合约和混合冲突负载分别报告，默认协议预算与实验预算分开。只统计最终确认的唯一成功交易。当前不提供未经本版实测的 TPS 或提升倍数。

随包保留适用的继承许可证和依赖声明。AIC 许可仅覆盖有权授权且明确指定的原创内容；软件分发与独立新链投入生产的授权范围分别核对，发行软件不代表获得整仓重新授权或主网上线许可。

历史正常/显式插桩矩阵、两套 Ubuntu 的四工具/四组件 CI 和真实 24 小时历史收益领取已完成，各自保留原冻结程序的证据范围。当前候选增加 VM 入口和线程 CPU 计量修复，并联合核验修复后的 CDT 运行库、23 份合约及零额领奖保护；当前完整原生、双引擎与恢复验证关闭前不正式发布。当前状态及原失败记录见 `docs/parallel-execution/PX7_V1_RELEASE_CHECKLIST.txt`。
