# 精确 1% 奖励计提复核 / Exact 1% reward review

状态：PASS，2026-10-31。只修正奖励计提，其他发行方式不在此次修改范围。

## 当前规则

- 每 364 天计提当前已发行量的 1/100，每 1461 天减半；1% 是计提系数，不是自然年固定 APY。
- 首次正权重直接投票激活计时；注册、余额和零权重投票不会激活，也没有 15% 总发行量门槛。取消投票、重启或排名变化不重置原有时钟。
- 实际出块累计未领份额。成功 claim 时才发行、转入 eosio.bpay，并按个人未领出块 / 全网未领出块分配。没有首个 BP 特权、投票分红或候补奖励；额外 4% 不发行，eosio.saving/eosio.vpay 不新增奖励资金。
- 首次领取距注册、后续距上次成功领取均须超过 24 小时；拒绝未授权、过早、零金额或资金不足的领取，原子回滚权益和计时。
- 使用整数最小代币单位与 unsigned 128 位中间值。跨减半段对齐余数后在该填池区间末尾向下取整；成功填池区间之间不保存小数最小单位。零支付失败保持区间，避免频繁失败领取清掉累计。
- 已发行量使用本次填池读取的 supply，后续填池可反映此前发行；上限及达到上限时的既有国库余额支付分支保持原样。其他额外发行方式保持用户既有设计。
- 全链停摆不产生额外出块权益，但既有按时间计提时钟继续经过停摆时间；缺岗保护不改变这一奖励时钟。
