host 注册包含 58 项 injected 注册，不应将全部 262 项解释为相同种类的用户可调用合约 API。候选调用也可能属于非 Chainbase 容器，因此计数不是“真实数据库访问总数”。注释和常规字符串不当作执行入口，条件编译分支保守保留。

`access-inventory.json` 逐文件保存 SHA-256、候选行号、操作类型、host 名称/注册宏/前置检查。没有命中候选的文件仍保存指纹，避免“函数体发生变化但扫描没匹配”被误认为没有变化。

扫描器自身也纳入指纹。快照检查是只读的；新增入口、删除文件或改了扫描规则都会产生差异，需要复审。

## 3. 自动工具不能证明的事情

- 函数别名、继承方法、宏生成入口、模板实例化和回调里的真实数据流。
- `find/get/create/remove` 究竟属于 Chainbase 还是其他容器，必须追踪接收对象。
- 只读代码是否引用正在变化的缓存、版本、块上下文或共享临时变量。
- 当前扫描范围之外的 VM、appbase、其他插件和第三方库是否影响线程安全。
- 同一源文件指纹不变但编译选项、依赖或运行配置变更造成的行为变化。

因此，源码清单不是运行时 allowlist，也不允许用“工具没找到访问”判定交易无依赖。所有记录当前仍默认待审查；如果以后建立运行时能力表，必须另写并测试失败关闭的策略。
