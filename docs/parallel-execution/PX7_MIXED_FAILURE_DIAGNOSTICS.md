## 预定运行与判定

使用相同三个 mixed suite、29 个用例，恰好三个独立 ASan/UBSan/LSan 诊断进程。普通 Boost 断言失败仍收集后续预定样本，只要一轮失败则总结果失败；检测器错误、崩溃或看门狗终止立即停止。默认压力 100、原生产准备 50ms/私有尝试 500ms、不绑核、不抑制错误。

这是取证批次，不是“重跑直到通过”。三轮未复现只能记录未复现；复现后根据实际阶段分类继续定位，不能补写上批缺失的现场。不得以该专项代替完整 worker、全节点插桩、真实 nodeos 或 TPS 验收。
