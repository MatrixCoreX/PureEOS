发现和拒绝过期执行结果。因此这些验证当时没有完成；不能推断对应链功能

本次缺失不等于节点无法启动、出块或最终确认。

  缺失、空文件、摘要变化、未列出的合约、符号链接或路径越界立即拒绝。
- 仅在精确核实原失败确为9个指定用例的相同缺文件错误后，继承前33个真实
  成功步骤的原时间和日志摘要。失败worker步骤不继承，必须整组重跑。
