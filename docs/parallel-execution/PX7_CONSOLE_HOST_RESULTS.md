## 源码变更

- 新增 `parallel_console.hpp`：11 种类型化打印事件，只拥有字节/数值位，不持有 WASM 内存或 controller 指针。单事件参数最多 64 KiB，整笔累计 256 KiB、1,024 个打印事件；还受原 4,096 个日志事件总限额约束。上限只选择整笔串行回退，不新增共识限制。
- `parallel_wasm_worker.cpp` 注册全部原打印接口，普通动作树、纯同步和混合执行器共享各自整笔的打印预算。字符串/跨度/128 位指针在检查控制台开关之前校验，保留 legacy 非空、未对齐和原始位语义；字符串扫描按块检查取消与原本次截止。关闭输出后不复制参数。模块 start 和每个调用帧使用当次能力，不把输出或计数留在缓存中。
- `parallel_action_tree.hpp` 捕获 `console_enabled`；树/步骤/同步/混合指纹版本更新，包含开关。混合上下文的两个开关必须相同；owner 从当前 controller 重新取得配置核对。旧 root/transaction/notification 接口没有完整绑定能力，调用打印仍明确回退，旧通知证明器也拒绝打印事件，不静默丢输出。
- `parallel_action_tree.cpp`、`parallel_sync_call.cpp`、`parallel_mixed_tree_journal.cpp` 逐事件验证类型、惰性字段、参数大小、写入位置和整笔预算。CF 帧只新增允许打印事件；数据库、通知、inline 或同步调用的原禁令没有一起放开。
- 私有同步 marker 改为“本帧之前的打印事件数”，**不是格式化字节数**。空打印也占一个事件，子帧不增加父帧计数；证明器在每个 call 处精确核对。无打印旧场景的标记仍为零。
- `parallel_canonical_adoption.cpp` 逐事件调用原 `webassembly::interface` 的 11 个打印接口。整数、名称、十六进制、SoftFloat/本机浮点格式均由原 host 完成。在同步调用前记录原 trace 当时的字节长度，调用后重新取得 trace 核对原 marker；不跨递归保存可能失效的 trace 引用。普通、通知和同步子帧各自拥有 console，不与通知组共享返回缓冲混淆。
- 原 `webassembly/console.cpp`、原注册和 ABI 转换代码不改；默认关闭并行、50ms 准备期和 500ms 私有尝试上限不改，原共识/治理/经济规则不改。
