## 失败证据

`live-reward-claims-attempt-12` 在22个候选均实际出块之后，重启主进程并移除
`nodeq` 签名材料，随后等待三完整零产出窗口超时。节点日志持续报告
`no recent votes received from others`，并非已经累计三次而未能拉黑。

原拓扑把全部22个身份配置在主进程，另一进程没有签名身份。移除其中一个后，
原生 `implicit_production_pause_vote_tracker` 把该身份识别为其他生产者，
但无任何健康的外部身份能发票，因此触发原有默认6秒出块保护。链停在
LIB11871，不能继续产生已最终确认的完整窗口；不能以延长等待解决。

原始失败和私有链数据保留。公开证据93108字节，SHA256：
`cf3eb1074ef74dafbf3186e6591a0187b26c003d36597e6038d57a6a745cb190`。
这不替代真正独立21/40节点的故障测试，也不说明原生出块保护应该关闭。
