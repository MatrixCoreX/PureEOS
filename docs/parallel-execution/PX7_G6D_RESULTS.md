## 当前实现边界

- 五族各十个实际私有接口：store/update/remove、find-primary/find-secondary、lower/upper、end、next/previous。由独占 secondary cursor group 执行，主键/二级写入共用时间顺序和总预算，全部二级游标事件进入已有 typed 日志。
- 在私有线性内存边界检查后复用原 `argument_proxy`。整数、SoftFloat 64/128 使用各自原类型的对齐；idx256 使用两个 uint128 的原 span，不把 32 字节误当元素数。标量零指针拒绝，合法的 span 零地址保留。
- lower/upper 的函数体只在命中时依原次序写 primary、secondary；之后按原 `database.cpp` 显式析构 secondary、primary 临时对象，未命中也保留复制回写语义。事件记录独立语义输出，不从别名写回后的内存反推数据库结果。
- 原浮点输入 NaN 限制在查询表之前执行；find-primary 的输出位置不错误套用输入限制。CF/只读/写权限/取消和失败丢弃约束继续有效。
- **五个正式采用保护和 ordered-batch 的 secondary 保护均未解除。** 简化 root-only 结果没有完整游标日志，后续仍须保持禁止；其他丰富结果也要先完成原 host 重放、冲突检测及真实链测试后才能准入。
