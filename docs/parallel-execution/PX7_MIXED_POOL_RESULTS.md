# PX7 c3c/m2a：混合任务工作池接入（实施中）

日期：2026-10-14。分支 `feature/parallel-tx-execution`，保留全部此前改动与原程序。证据目录 `build/local-tests/parallel-mixed-pool-20261014-KdE3jF/`。

## 范围与安全边界

新增自持 `isolated_mixed_tree_job`，工作池六种模式严格互斥。混合执行器与旧执行器切换时销毁旧模式缓存，每个 worker 至多保留一个执行器的有界模块缓存。结果按每个普通步骤自身和所有同步子帧的独占 CPU 求和，空代码尾通知不能抹去真实执行区间；失败清除所有结果，不发布成功前缀。ordered batch 识别独立混合指纹并检查整个写集，但仍不提供权限或正式账本采用能力。

新增本地 `mixed_required` 提示：旧树中的普通通知/inline 首次调用同步接口，或旧同步普通根首次发送通知/inline 时请求混合模式。原普通根的 `sync_required` 保留。CF 及同步子帧越权发送仍为 unsupported，不能通过模式升级获取能力；同步子帧的 inline 两入口显式先做 action-only 检查。

本阶段 **尚未接入 controller 的模式升级、正式混合采用器、生产/验证 CPU 消费及真实混合节点**。controller 暂时把新提示作为安全回退；不能把工作池成功称为已上链采用。原经济/治理/生产预算和默认开关不变。调度策略仍是原共享任务队列，没有宣称修复 G7 编译扇出或超时风险。
