## 已实施

1. CDT 测试器：成功须退出 0；信号终止不能算预期编译失败；显式 exit-code=0 也校验；BUILD_FAIL 正确分派。
2. varuint32 有界解码：在移位前拒绝超长/溢出；输出在失败时保持原值；有符号编码避免带符号左移 UB；维持不溢出的非最短编码接受策略。
3. datastream 改为有界偏移，避免构造越界指针再检查；非法 skip 拒绝、非法 seek 返回 false 且不破坏位置；读取、写入、计数溢出和基本类型容器在分配前检查。
4. 非基本类型 vector/list/deque 按元素解码，不先按伪造总数巨额分配；不把“元素数必须 <= 剩余字节数”误用于零字节序列化类型。
5. 轻量分配器新增可测试的独立核心：16 字节对齐、长度/乘法/页数检查、仅不足时 memory.grow、记录旧块长度、realloc 有界复制及失败前不发布新游标。free 仍为实例生命周期策略。
6. 节点线程池采用每个逻辑 worker 的独立条件变量；稀疏任务仅唤醒目标 worker。大批次仍保留共享任务队列；停机唤醒所有等待者，VM 和状态仍独占。
7. 测试看门狗 `wait_produced` 从 100 秒调整为 900 秒：单个完整 21 人轮岗间隔已有 126 秒，原 100 秒不充分。这不是修改生产轮岗或 CPU 配额。

## 保留的失败及修复

- `wasm-attempt-1`：把链接对象交给只接受源码的 ABI 生成器，准备失败。
- `wasm-attempt-2`：官方驱动先选择原 runtime，与显式新对象产生重复符号，链接失败。
- `wasm-attempt-3`：独立 SDK 缺少根目录 `cdt.imports`，链接失败。
- 改为独立复制驱动/链接器、完整 SDK 布局及独立重编 archive；未覆盖官方包。
- `contracts-attempt-1`：容器逐项解码的 `T element{}` 对含显式默认构造成员的类型失败。改为与 allocator 一致的 `T()` 值初始化，加入回归；随后新 SDK 原生/真实链重测及完整合约重编通过。**没有通过删除 msig 编译目标来隐藏 SDK 泛型问题。**
- `wasm-attempt-4/5` 的通过对应各自冻结输入；最终新增“先写后拒绝”的撤销测试另放 attempt-6，不混用摘要。

## 不能据此宣布完成的内容

- 分配头会增加每块少量空间，非基本类型容器的渐进增长也可能增加分配/移动成本；正确性通过不代表性能已改善，须以真实负载另验，不能直接替换正式 SDK 后宣称提速。
- 整池/整节点 sanitizer、新 nodeos 新候选统一回归、当前 40 节点观察器修复及整轮补测未完成。
- 真实 24h 领奖及拉黑后历史未领奖励实领组合，分别需要其最终证据；不由本批模拟替代。
- 最终候选同版本、同引擎、同额度串并行性能门槛尚未取得。当前低配轮次不重启 TPS。
- 流水线、LLVM 大迁移是独立后续设计/验证，不因本批基础修复勾选完成。
