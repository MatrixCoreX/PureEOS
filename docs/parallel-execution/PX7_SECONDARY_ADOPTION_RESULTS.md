## 实现范围

- `parallel_canonical_adoption.cpp`：通知、inline tree、sync、mixed 共享内部类型化二级重放器，调用原 `host_context` 的五类索引。保留原 RAM/payer、所有权、祖先游标失效；补齐注册层的 CF/只读/NaN 前置条件，比较原句柄、精确键位和查询输出。主键与二级写共享绝对顺序。正式写入后的不一致抛出异常，走原整笔 undo，不返回 false 后重复执行整笔。
- `parallel_ordered_batch.hpp/.cpp`：旧简化 action/transaction 结果仍拒绝二级索引；丰富结果进入其各自完整证明和原生采用器，协调器回调本身不代表已采用。store/remove 使共同表结构变脏，包含增删抵消的 ABA；二级 update 按表/索引维护脏主键和有序候选位置。检查选中记录、缺失结果、重复键、上下界、首尾和相邻查询锚点，保留所有中间位置。浮点采用原 SoftFloat 排序，精确位相等与排序等价分开。
- 记账在 canonical callback 前完成，限制每结果 4,096 次写/读查询、整批最多 64 × 4,096 次写；局部分配失败停用推测尾部并走原串行。owner 检查点异常不被分配失败处理吞掉，预检和正式回调均禁止重入/关闭同一批次。
- `controller.cpp`：生产记账途中检查真实出块截止、取消与 pending generation，不把已经结束的私有阶段截止当成交易拒绝；验证侧保留原 interrupt 异常。
