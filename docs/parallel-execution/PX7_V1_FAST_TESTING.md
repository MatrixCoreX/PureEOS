## 快速通道

入口：`tests/v1_fast_regression.py`。

- 不配置、不编译：直接复用候选已构建的 11 个 ELF；前后核对全部 SHA256。
- 要求 configure/build/真实三工具来源检查已通过，任何已记录失败都拒绝启动。
- 真实检查 nodeos/cleos/keosd 完整版本与源清单 SHA 一致。
- 资源管理器 15 项，含有限 CPU/NET 极端权重、回滚和原额度公式。
- worker 的整数、浮点、哈希、二级索引、context-free、并发重叠、console、
  混合调用树、inline 授权和最终 RAM 检查，解释器/JIT 分别实际运行。
- controller 的不同行并行/共享余额回退和真实 token 转账，双引擎分别运行。
- 三个 prefix-refresh 测试内部已经遍历解释器/JIT × 1/4/16 workers，
  快速通道只调用一次，不再外层按引擎重复一遍。内部覆盖没有减少。
- 访问提示、worker 唤醒、不可变输入三个组件程序。
- 显式选定治理、公示期、投票、REX、费用流向、10/90、奖励减半、激活、
  小委员会、永久黑名单移出等业务案例。详细清单在入口的 NATIVE 常量。
- 报告必须包含全部指定案例的实际 Boost passed 记录，退出 0 本身不够。
- 文件只读挂载/自有副本、无外网、最多 2 CPU/2GiB 内存，15 分钟 guest 上限。

输出状态明确是 `smoke-passed-not-release`，`release_ready=false`，
不能代替完整 59 步、真实时钟、跨主机或正式 TPS 门槛。
