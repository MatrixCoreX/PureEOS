# Controller source for review

These are historical bounded controllers, not a portable release/bootstrap kit.
Their immutable remote paths and completed-window guards deliberately reject
reruns. Do not restart this campaign or treat the old approval as a new window.
All builds/tests must run remotely. A new qualification needs a new isolated
root, explicit applicable resource authorization and reviewed dependency hashes.
Host-access helpers/configuration and all credentials are intentionally excluded.
The staging script includes the unchanged wire helper that was omitted in the
first repair qualification; both original failure and passing retry are retained.
See source/overlay hashes and per-object argv in ../evidence for actual execution.
