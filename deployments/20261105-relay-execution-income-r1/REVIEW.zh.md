# 中继执行费分配升级审核

此审核包是候选，生效以同一 Chain ID 上原生 devpropose 公示和匹配 devexec 的不可逆回执为准。

有商业中继的 ksend / withdraw / cancel，将新产生的执行费与中继手续费计入实际提交 BP 的可领取收入。实际 RAM 支出先扣除，不能作为 BP 收入；用户总费用和完整本金不变。中继手续费仍按基础费的10%–30%向上取整，受持有人签名费率及总费用上限约束。执行费是市场参考报价，不是逐笔精确实耗报销，中继收入也不等于净利润。

命名充值、selfout、selfcancel及旧退款路径的原费用归属不变。旧 network 储备不迁移、不追溯分配；此前观察2352原子单位，其中KEY672、创始BP1680。即使旧行归档在BP名下，也不能通过claim领取。资金仍由KEY托管，合约只把新增可领取收入记入relay_earned，合法持有人用原有免费claim领取。

ABI、表布局、签名报文、代次/防重放、BP资格/封禁、审核代币及系统代码摘要、自动购RAM、准备金等式不变。旧feereceipt.retained_base字段保留，表示RAM之外的执行费；依据代码版本及对应receipt.relayer判断归属，历史交易保留原解释。

部署须先发布本精确包与源代码，再完整TEST1800链秒公示及BP否决检查，最后匹配执行。正式7天不改。无链重置、BP暂停、投票/保证金/总量上限/原生系统变更、新服务器或TPS。所有构建、验证和浏览器检查远端进行。具体摘要与实际检查数以REVIEW.json为准，保留前两次解析器失败记录。
