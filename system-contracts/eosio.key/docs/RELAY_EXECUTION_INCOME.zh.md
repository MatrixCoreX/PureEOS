# 执行费归实际中继：升级政策

状态：候选开发与验证中，未上线；实际生效以原生提案和不可逆执行为准。

有商业中继的 ksend、withdraw、cancel：先扣除实际原生 RAM 支出，再将执行费与中继手续费一并计入本次实际提交 BP 的 relay_earned；BP 用原有 claim 全额领取，claim 本身不收应用手续费。资金仍由合约托管至合法领取，并非每笔直接向 BP 转账。

用户总费用、10%–30% 中继手续费率、向上取整、签名费率及 max_fee 上限、完整本金、自动购 RAM、资源市场倍率和资格检查不变。中继手续费=基础手续费×所选费率；基础手续费=执行费+实际 RAM 支出（含最低费用补足）。中继收入=总手续费−实际 RAM 支出；这是收入，非保证净利润，也不是逐笔精确实耗 CPU/NET 报销。

命名充值、selfout、selfcancel 没有商业中继，原执行费仍记网络储备，不凭空分给 BP。此前网络储备不迁移、不追溯分配；即使历史 network 行挂在 BP 名下，仍不可通过 claim 领取。

ABI、表布局和签名报文保持不变。feereceipt.retained_base 是保留的旧字段名，金额表示 RAM 之外的执行费；配合对应 receipt.relayer 和已审核代码版本判断收款归属，不能把旧交易重新解释为新分配。

例如总费0.0294AIC、RAM0.0037、执行0.0189、中继手续费0.0068：新规则下中继可领0.0257，用户仍付0.0294、收款本金不变。
